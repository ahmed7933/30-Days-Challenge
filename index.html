🚀 كيفية الرفع على GitHub ونشره على Vercel في دقيقة:

  1. قم بإنشاء مستودع جديد على حسابك في GitHub (مثلاً: challenge-tracker).
  2. ضع ملف هذا الكود باسم index.html في المجلد الرئيسي وارفعه (Push).
  3. افتح موقع Vercel.com واضغط Add New Project، ثم اختر مستودع الـ GitHub.
  4. اضغط Deploy، وسيعمل موقعك فورياً برابط عالمي سريع ومجاني!
